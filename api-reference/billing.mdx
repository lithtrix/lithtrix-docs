Pricing shape ruled D173 (2026-08-19), amended D174 (2026-08-20): rolling-30-day free floors plus a per-action credit meter. Past a free floor the API returns 402 `INSUFFICIENT_CREDITS` unless the agent has credit. There are no paid tiers. **`GET /v1/capabilities`** is authoritative for numeric rates and tier copy.

<Warning>
**Payments are not offered.** Billing runs on the Airwallex **sandbox** (test mode). Do not send a payment. The routes below still exist in the API. Credits granted in test mode are test money and carry a `[SANDBOX]` ledger note.
</Warning>

## Check status

```bash
GET /v1/billing
Authorization: Bearer ltx_your_key
```

Returns a snapshot of the authenticated agent:

| Field | Meaning |
|-------|---------|
| `tier` | DB tier column (`spark`, legacy pack names, or `starter`/`pro` for older subscriptions) |
| `credits_remaining_usd` | Current spendable credit balance (USD string, 4 decimal places) |
| `credits_expire_at` | Legacy pack expiry for historical rows; purchased slider credits do not expire (D174) |
| `tier_label` | Human-readable tier name |
| `auto_topup` | `true` if auto top-up is configured |
| `over_limit` | `true` if storage, memory, or parse quota is at cap |
| `payment_processor` | Configured processor (`airwallex`) |
| `payment_customer_id` | Processor customer id when present |
| `recharge_consent_id` | Saved MIT consent for auto top-up |
| `memory_ops_this_month` | Memory operations logged this UTC month |
| `memory_storage_bytes` | KV JSON storage (bytes) |
| `blob_embed_storage_bytes` | Bytes used by parsed document chunk embeddings |
| `combined_memory_storage_bytes` | `memory_storage_bytes + blob_embed_storage_bytes` |
| `search_calls_this_month` | Web-discovery calls this UTC month |
| `browse_calls_this_month` | Browse calls this UTC month |
| `parse_ops_this_month` / `parse_ops_lifetime` | Parse usage |

## Free floors (D173/D174)

Before any credit is charged:

| Action | Free floor | Window |
|---|---|---|
| Memory write | 1,000 | Rolling 30 days |
| Search | 50 | Rolling 30 days |
| Browse | 20 | Rolling 30 days |

Past the floor the API returns 402 `INSUFFICIENT_CREDITS` unless the agent has credit. If the agent has credit, the meter is memory write **1 credit ($0.01)**, search **2 credits ($0.02)**, browse **static 3 credits ($0.03)** / **dynamic 5 credits ($0.05)**. See [Pricing](/pricing).

## Payments are not offered

Payments are in sandbox/test mode and are not offered. There are no paid tiers. Do not send a payment.

These routes still exist in the API and are listed so the reference stays complete:

| Route | Status |
|---|---|
| `POST /v1/billing/credits/checkout` | Exists. Sandbox/test mode only. Do not send a payment. |
| `GET /v1/billing/config` | Exists. Returns the sandbox processor config. No auth. |
| `POST /v1/billing/setup-intent` | Exists. Sandbox/test mode only. |
| `POST /v1/billing/auto-topup` | Exists. Sandbox/test mode only. |
| `POST /v1/billing/packs/checkout` | Retired. Returns **410 Gone** (`PACK_CHECKOUT_RETIRED`). |

## Webhook (ops)

`POST /v1/billing/airwallex/webhook` — Airwallex HMAC-signed events. Configure `AIRWALLEX_WEBHOOK_SECRET` on the host. Slider purchases grant on `payment_intent.succeeded` with metadata `purchase_type=slider`.

## Environment (ops)

- `AIRWALLEX_CLIENT_ID`, `AIRWALLEX_API_KEY`, `AIRWALLEX_PUBLISHABLE_KEY`, `AIRWALLEX_WEBHOOK_SECRET`
- `AIRWALLEX_BILLING_PAGE_ORIGIN` — CORS origin for [billing.lithtrix.ai](https://billing.lithtrix.ai)

See also [`GET /v1/capabilities`](https://api.lithtrix.ai/v1/capabilities) for the `pricing` block and per-call rates, and [Pricing](/pricing) for the full D173/D174 shape.
